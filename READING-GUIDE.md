# Как читать этот репозиторий

Для любого читателя — человека или ИИ-ассистента, не только Claude.

## Что это

Мастерская **интерфейса** FractalOS — настольного окна (Windows, Qt/PySide6).
Через это окно хозяин-оператор работает с несколькими ИИ-ролями.

- **Здесь только дизайн:**
  - опись текущего окна;
  - прототипы нового окна (статичный HTML);
  - снимки экрана;
  - решения;
  - заметки для переноса в Qt.
- **Кода ядра FractalOS здесь нет.** Он у хозяина локально; туда же локальная
  команда переносит дизайн.
- **Язык документов — русский.**

## Какую ветку читать

- Пока PR не слиты, **всё лежит в ветке `round-05`**. В `main` только входные
  документы.
- Раунды лежат в ветках `round-00` … `round-05`. Каждая следующая содержит
  предыдущие.
- PR раундов 0–5 открыты в `main`, каждый следующий содержит предыдущие.

## Порядок чтения

1. **`sessions/2026-09-24.md`** — пересказ всей работы: что просил хозяин, что
   сделано, выводы, что нужно от ядра, что дальше. **Начните отсюда.**
2. **`docs/PRODUCT-MODEL.md`** — из чего состоит система, роли и их
   инварианты. Это закон для дизайна.
3. **`DECISIONS.md`** — журнал решений: что выбрали, что отвергли и почему.
   Новые — сверху.
4. **`rounds/05-composer/shots/*.png`** (поле ввода), **`rounds/04-diff/shots/*.png`**, затем **`rounds/03-clarity/shots/*.png`** —
   как выглядит окно сейчас. Картинки быстрее текста.
5. **`rounds/NN-*/NOTES.md`** — по раундам. В каждом:
   - что сделано;
   - снимки;
   - **«Qt: как собрать»** по каждому компоненту;
   - что нужно в данных ядра;
   - проверки.
6. По необходимости:
   - `docs/CURRENT-UI.md` — опись старого окна;
   - `docs/ANSWERS-R0.md` — ответы из кода на вопросы дизайна;
   - `docs/current-shots/` — снимки старого окна;
   - `rounds/00-audit/NOTES.md` — разбор старого окна.

**Что уже устарело.** Раунды идут друг за другом, и позднее отменяет раннее.
Актуальный интерфейс — `rounds/05-composer/index.html`: в нём все виды в последней
редакции, поле ввода — из раунда 5. `rounds/01-terminal` и `rounds/02-journal` — история.

## Словарь

| Слово | Значение |
|---|---|
| **хозяин** | Человек за окном. Ставит работу, правит закон окна, выдаёт гранты, принимает дифф. |
| **рот** | ИИ, с которым хозяин разговаривает. Это и есть чат — в окне он один. Передаёт объём работы в найм. Не выдаёт себе грант и не нанимает руки по сырому тексту хозяина. |
| **мозг** | ИИ для суждений и вердиктов. Пишет закрытый бриф для рук. Код не пишет. |
| **руки** | ИИ-исполнитель (найм DSH). Правит песочницу или копию дерева проекта. Без гранта не пишет вне песочницы. |
| **учитель** | Правила гигиены после найма (CLOSE-HIRE): что закрепить в памяти, что поставить в очередь хозяину. Это не персона и не отдельный чат. |
| **найм** | Один запуск рук по брифу. У него есть id, например `7c1e40b2`. |
| **бриф** | Задание для рук от мозга. Руки видят только его. |
| **расписка** | Отчёт найма: ждали — получили; подтверждено или нет. |
| **копия дерева** | Копия проекта, в которой работают руки. Живой проект не трогается. |
| **дифф** | Изменения рук в копии. Ждёт хозяина: применить в живое дерево или отклонить. |
| **грант** | Разрешение рукам писать вне песочницы. Выдаёт хозяин, на время (30 минут или 8 часов). |
| **замок / «пишет»** | В проект пишет только один. «пишет: никто / руки». |
| **строка состояния** (в ранних раундах — «строка закона») | Строка под заголовком окна: всё ли работает, кто отвечает, грант, кто пишет. |
| **Состав** | Вид с картой частей системы и их здоровьем. |
| **Журнал** | Вид с историей сессий. |
| **маскот** | Фирменный персонаж. Маленький — в строке активности над полем ввода. |

## Как смотреть прототип

- **Открыть:** `rounds/05-composer/index.html` двойным щелчком. Сеть и сборка не
  нужны. Все данные выдуманы.
- **Клавиши:**
  - `Ctrl+1…4` — виды;
  - `Ctrl+K` — команды;
  - `F1` — подсказки по окну.
- **Готовое состояние** открывается добавкой к адресу после `#`, например
  `index.html#s=hire&v=diff`. Параметры:

| Параметр | Значения |
|---|---|
| `s` — сценарий | `ok` — всё работает; `hire` — идёт найм, руки пишут; `grant` — руки просят грант; `degraded` — память без связи, мозг на запасной модели, руки выключены; `busy` — рот отвечает; `retry` — найм не дошёл |
| `v` — вид | `talk` — Разговор, `sostav` — Состав, `journal` — Журнал, `diff` — Дифф |
| `side` | `sostav`, `journal`, `diff` — открыть рядом с разговором |
| `sel` | часть в «Составе»: `mouth`, `brain`, `hands`, `mem`, `grant`, `lock`, `teacher`… |
| `j`, `jf`, `q` | Журнал: сессия (`cur`, `s-parser`…), фильтр (`all`, `wait`, `err`, `grant`), поиск |
| `d`, `dv`, `rej`, `done` | Дифф: какой (`7c1e40b2`, `6e04c2d1`…); сколько файлов отмечено просмотренными; `rej=1` — открыть отклонение; `done=apply` — показать после «Применить» |
| `c` | поле ввода (раунд 5): `focus`, `multi` — несколько строк и вложение, `slash` — меню команд, `hire` — маршрут «мозг → руки», `btw`, `opts` — меню «···», `plus` — меню «+» |
| `a=1` | альтернатива пропорций поля (раунд 5) |
| `help=1` | подсказки `F1` |
| `palette=all` | открыть палитру команд |
| `f=sans` | лента пропорциональным шрифтом (по умолчанию моноширинный) |

Готовые снимки этих состояний — в `rounds/NN-*/shots/` (список — в
`shots.json` раунда). Размеры: 1440×900, 1920×1080, иногда 2560×1440.

## Правила, которые нельзя нарушать при доработке

- **Роли и их границы** — `docs/PRODUCT-MODEL.md`:
  - чат один;
  - руки не пишут вне песочницы без гранта;
  - грант выдаёт только хозяин;
  - в проект пишет только один.
- **Цвет:**
  - бирюза `#09F5E5` — акцент;
  - золото `#E2A84A` — внимание хозяина, в бирюзу его не перекрашивать;
  - тёмная тема, фон `#1C1C1C`.
- **Всё собирается в Qt Widgets + QSS.** Никаких эффектов, которые живут только
  в браузере; анимации короткие и отключаемые.
- **Контраст текста** — не ниже 4.5:1.
- **Интерфейс рассчитан** на одного человека за настольным компьютером:
  клавиатура прежде мыши, русский текст.
- **Желания хозяина** — `sessions/2026-09-24.md` §3.2:
  - память без чисел;
  - лента моноширинная;
  - окно по умолчанию одно;
  - ничего полезного не удалять.
