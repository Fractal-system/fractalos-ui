- Облако — советчик. Сильнее в архитектурных решениях и в узорах, которые уже нарисованы в этом репозитории. Код ядра не читает и не получает. Сюда приходят только задачи про вид и про то, как лучше устроить уже намеченное.
- Руки кодят объём по закрытому брифу. Вкус им не отдают.
- Ответ — в этом запросе, со ссылкой на файл и раздел. Если в файлах этого нет — так и напишите. Молчание не считается решением.

## Поправка

В пересказе щелчок по любой части строки состояния ведёт в «Состав» (`sessions/2026-09-24.md` §3.1, приоритет 1).

Хозяин 25 сентября развёл два жеста:

- Вкладки «Разговор / Состав / Журнал / Дифф» — это разделы.
- Щелчок по «рот», «мозг», «руки» или по гранту в строке состояния — не переход в «Состав». У каждого своё маленькое окно без новой панели: тот же тёмный фон, закрытие крестиком. Пример: щелчок по «рот» — смена модели. «Состав» остаётся картой: что это за часть и чего она не может (`rounds/03-clarity/shots/05-sostav-1920x1080.png`).

Разрешения он назвал тремя состояниями, не окном времени: **нельзя / по запросу / автоматически**. Пока только для записи. Права администратора окно ещё не спрашивает — тумблер не рисовать. Это для контура сессии (рот и его части: мозг, руки).

Нарисованный грант другой: карточка в ленте «Разрешить на 30 минут / На 8 часов / Не разрешать» (`DECISIONS.md` 1.4, снимок `rounds/03-clarity/shots/03-grant-1920x1080.png`). Закон дизайна: грант выдаёт только хозяин, на минуты, каждое действие разово (`docs/PRODUCT-MODEL.md`, раздел «Инварианты ролей»).

## Варианты

По умолчанию предлагаем **первый**. Если он ломает закон ролей — отвергните и скажите, какой из двух других честнее.

1. **По умолчанию.** Строка состояния не открывает «Состав». Щелчок по роли открывает маленькое окно. «Состав» открывается вкладкой и остаётся картой. Три слова про запись: «нельзя» — не предлагать разрешение; «по запросу» — остаётся нарисованная карточка 30 минут / 8 часов, когда руки просят запись; «автоматически» — хозяин сам включил стояние разрешение, рот и руки себе его не выдают. Права администратора не рисуем, пока окно их не спрашивает.
2. Оставить как нарисовано: щелчок по строке открывает «Состав», грант — только окно времени. Три слова хозяина считаем подписями к уже нарисованному: нельзя = не разрешать, по запросу = 30 минут, автоматически = 8 часов.
3. Маленькие окна для ролей — да. «Автоматически» не делаем стоянием грантом: это только «не спрашивать снова в этой сессии», а каждое действие всё равно разовое. Так ближе к формулировке «каждое действие — разово» в `docs/PRODUCT-MODEL.md`.

Просим ответ словами: какой вариант, что в нём ломает закон, что оставить как в beta. Картинку раунда 5 не рисовать в этом ответе.
