# FractalOS — модель продукта для дизайна

FractalOS — десктопная оболочка (Windows, Qt), в которой хозяин работает с ИИ-агентами над своими проектами. Один человек, один экран, русский язык.

## Роли (закон)

| Роль | Кто | Делает | Не делает |
|---|---|---|---|
| **Хозяин** | человек | ставит работу одним текстом, решает закон, выдаёт гранты, принимает дифф | — |
| **Рот** | чат (по умолчанию Grok; запасной — Flash) | разговаривает в одном чате, отвечает, передаёт объём в найм | не выдаёт себе грант; не нанимает по сырому тексту хозяина |
| **Мозг** | слот `brain_axis`: Grok или Flash | суждение, вердикты, пишет закрытый бриф для рук; у Flash две двери — «только ответ» и «только чтение» | не пишет код; не путать с внешними агентами настройки |
| **Руки** | DSH (исполнитель по найму) | объём кода по закрытому брифу, в песочнице | не пишут вне песочницы без гранта хозяина; не обходят замок писателя |
| **Учитель** | правила (не персона) | гигиена после найма: что закрепить в памяти, что в очередь хозяину | не LLM, не отдельный чат |

## Инварианты ролей, которые должен показывать UI
- **Один чат.** Рот — это и есть чат. Второго чата нет.
- **Найм = закрытый бриф → песочница → расписка.** Руки работают по брифу; результат подтверждает **файл-расписка** на диске (важнее кода возврата). Незавершённое → повторный найм или аварийный мозг.
- **Копия дерева.** Для корней fractal (FractalOS, fractalmem, fractalprofit) руки правят **копию**; результат — **дифф**, который проверяет и применяет тот, кто дал задание. Живое дерево руки не пишут.
- **Один писатель.** Пока кто-то пишет в дерево проекта, второй не пишет (замок). Занято → отказ, не очередь.
- **Грант.** Запись вне песочницы — только по гранту хозяина на N минут, каждое действие — разово (`/approve <минуты>`). Рот и руки гранта себе не дают.
- **Слоты.** Рот / мозг / руки включаются и выключаются на рельсе; руки выключены → найма нет, демон тёплый.
- **Закон окна** (правила, роли, эти документы) правит только хозяин; руки его не трогают.

## Из чего состоит система (для экрана «состав и здоровье»)

| Часть | Что это | Здоровье (что проверяемо) |
|---|---|---|
| Окно | Qt-оболочка: чат, композер, рельс, строка статуса | запущено |
| Рот | Grok ACP-сессия (или Flash-чат) | отвечает / недоступен |
| Мозг | Grok или Flash по слоту | доступен / выкл |
| Руки | mux `:11436` + воркеры DSH (slim / lean / full) | готов / греется / слот выкл / не поднялся |
| Память | fractalmem: база знаний и истории хода, хуки хостов | работает / выкл / нет связи |
| Грант | канал одобрения записи | выдан до ЧЧ:ММ / нет |
| Замок писателя | кто сейчас пишет в проект | свободен / занят кем |
| Классификаторы (System 1) | быстрые метки: Needle (развилка найма), Jev (разметчик), Laya (локальная модель, в резерве) | тень, не решают |
| Атлас | карта частей системы (103 узла) и правило «атлас следует за деревом» | синхронен / расходится |

## Проекты
Хозяин выбирает проект (корень) в заголовке. Руки работают в корне проекта. Внешние проекты (например, metrprod) живут по своим правилам; fractal-корни — через копию и дифф.

## Журнал сессий (что есть в данных)
Сессия рта; наймы рук в ней (бриф, старт, прогресс, итог, расписка, дифф); обращения к мозгу; гранты; ошибки. По каждому найму есть итог `done.md` и дифф.
